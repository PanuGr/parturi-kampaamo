# Authentication & Access — Parturi-Kampaamo

All machine-readable resources on this site are public.
No login, API key, or token is required.

## Public resources (no authentication)

- `/llms.txt` and `/llms-full.txt` — site content for AI assistants.
- `/.well-known/api-catalog` — resource catalogue.
- WebMCP tool `get_salon_info` (declared by the page) — read-only salon information, no authentication.

## Authenticated endpoints

None. This is a static website with no user accounts, logins, or private APIs.

Online booking is handled by an external booking system:
https://demo.aikanen.fi/c/demo-kampaamo
Accounts or credentials created there are governed by that provider's own terms.
